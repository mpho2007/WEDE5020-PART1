# Apex Auto Repair Website

## Project Overview

Apex Auto Repair is a responsive business website created for an automotive repair company. The website provides information about the business, its services, gallery, enquiry form and contact details.

The website is designed to provide visitors with an easy and professional way to learn about Apex Auto Repair and contact the business.

## Website Pages

The website contains the following pages:

* **Home** – Introduces Apex Auto Repair and highlights the main benefits of the business.
* **About Us** – Provides information about the company, its mission and vision.
* **Services** – Displays the automotive repair and maintenance services offered.
* **Gallery** – Shows images related to the workshop, vehicles and repair services.
* **Enquiry** – Allows customers to submit an enquiry about a vehicle or service.
* **Contact Us** – Provides contact information and business opening hours.

## Technologies Used

The website was developed using:

* HTML5 – Used to create the structure and content of the webpages.
* CSS3 – Used to style the website and create a consistent visual design.
* Images – Used to improve the appearance of the gallery and website content.

## Navigation

All pages contain a navigation menu that allows users to move between:

**Home | About Us | Services | Gallery | Enquiry | Contact Us**

The same navigation structure is used throughout the website to provide consistent and easy navigation.

## Installation and Usage

No special software or server is required to view the website.

1. Download or copy the project folder.
2. Make sure all HTML files and `style.css` are in the correct folder.
3. Make sure the images are stored inside the `images` folder.
4. Open `index.html` using a web browser such as Google Chrome, Microsoft Edge or Mozilla Firefox.
5. Use the navigation menu to access the different pages.

## Purpose of the Website

The purpose of the website is to:

* Provide information about Apex Auto Repair.
* Display the services offered by the business.
* Allow customers to view automotive-related images.
* Give customers access to contact information.
